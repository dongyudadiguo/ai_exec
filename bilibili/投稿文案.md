## 简介

AI Exec 是一个极简、透明、可在本地查看执行过程的 Python AI Agent 运行器。

它用 49 行核心执行器跑通完整 Agent 循环：请求 Responses API、接收 Function Calling、执行本地 Python，再把结果回传给模型，直至任务完成。配套 Web 界面支持工具状态、完整输出、附件输入、Token 估算和一键停止。

项目地址：
https://github.com/dongyudadiguo/ai_exec

⚠️ 安全提醒：Python 工具会继承当前用户权限，AI Exec 不是沙箱。请只使用可信模型与提示词，高风险任务建议放入虚拟机或 Windows Sandbox。
