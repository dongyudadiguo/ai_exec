# 《AI Exec》视频脚本

## 1. 让 AI 不只回答，而是直接动手（0.00s–9.60s）

如果 AI 不只回答，还能检查文件、运行代码、连续完成任务呢？这就是 AI Exec。

## 2. 49 行，跑通一个 Agent 循环（9.60s–20.42s）

这是一个极简的本地 Agent。四十九行 Python 跑通核心循环：请求 Responses API、执行工具、回传结果。

## 3. 执行过程，完全透明（20.42s–31.94s）

浏览器写入任务，模型生成 Python，工具返回输出，直到最终答案。全过程保存在 input 点 JSON，透明可查。

## 4. 三步开始使用（31.94s–40.89s）

安装 Python 和 requests，配置接口、密钥与模型，再双击 view 点 V B S，本地界面就打开了。

## 5. 工具调用，实时可见（40.89s–52.53s）

AI 可以检查项目、读取文件、运行命令。页面实时展示工具状态、完整输出和最终结果，也支持拖入文件与图片。

## 6. 轻量，但不简陋（52.53s–61.91s）

你还能继续运行、估算上下文，并一键停止进程树。没有笨重框架，适合学习和二次开发。

## 7. 重要：它不是沙箱（61.91s–71.51s）

注意，Python 工具有当前用户权限，并不是沙箱。高风险任务请使用虚拟机或 Windows Sandbox。

## 8. 足够小，足够透明（71.51s–82.21s）

安装、配置、接口约定和安全说明都在 README。想看一个小而透明的 Agent，就试试 AI Exec。
